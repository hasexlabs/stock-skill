# Stock Skill

This repository contains the `picks-and-shovels-research` skill for evidence-backed research on public companies that provide tools, components, materials, instruments, infrastructure, or specialized services to emerging industries.

## Included skill

- [`picks-and-shovels-research`](./picks-and-shovels-research/): workflow, screening gates, scoring framework, source standards, price-history analysis, and report templates.
